# Confirmed Decisions

## 通用

- 组件优先使用 `Expo UI`
- 所有页面按手机长宽比展示
- 缩略图统一输出到项目根目录 `thumbs/`
- `en` 语言枚举已改为 `en-US`

## UI / 页面

- 首页未申报态单独设计，不显示底部导航
- 事项页顶部使用圆形 `+` 按钮新建事项
- 事项页已取消多选操作
- 底部导航改为 icon，不使用上方圆点指示

## 国际化

- 当前支持：
  - `zh-CN`
  - `zh-TW`
  - `en-US`
- 导出缩略图需要按不同国际化配置生成多版本图片

## 皮肤系统

- 引入皮肤机制，页面布局和样式由皮肤决定
- 当前皮肤：`skin-001`
- 当前皮肤中文名：`海盐蓝绿`
- 皮肤定义页面布局方式和组件配色
- 采用受控组件集合，不允许远程任意 React 组件执行
- 皮肤包必须完整下载到本地后才允许切换或加载
- 每个皮肤有自己的 `skinVersion`
- 每个皮肤声明适配的 `featureVersion`
- `featureVersion = app semver major.minor`
- 皮肤要求的功能版本高于当前 app 时，要提示升级 app 或更换风格

## 文档整理规则

- 面向 AI 的识别、流程、摘要文档统一放在 `.ai/`
- 产品原始文档和设计原始文档继续保留在仓库正常位置
