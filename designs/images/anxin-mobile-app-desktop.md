# anxin-mobile-app — desktop

**Preview file:** designs/previews/anxin-mobile-app-desktop.png
**Spec SSOT:** designs/specs/anxin-mobile-app.md

## Layout

1440 x 1024 desktop design board on a mist background. Show three iPhone-style frames side by side with consistent safe areas:

1. Home dashboard
2. Plan detail
3. Execution timeline

Use a quiet label rail above the frames with the brand `安心` and the phrase `提前交代，事后有序`. The design board is not a marketing landing page; it is a UI system preview for product modules.

## Modules

- Home dashboard: active flat sealed-plan card, `当前正常`, next confirmation date, readiness checklist, quick actions.
- Plan detail: flat plan layer title, matters/files/helpers/trigger-rule sections, seal band showing `已生效`.
- Execution timeline: safe empty/rehearsal state, step cards for confirmation, helper receipt, review, file release.
- Bottom tabs in every frame: `首页`, `预案`, `执行`, `我的`.

## Visual details

- Background: `#F3F8F7`
- Light cards: `#FFFEFA`
- Primary teal: `#0A6B63`
- Deep text: `#1B2D3A`
- Seal amber: `#B7791F`
- Muted panel: `#E7EFEC`
- Risk brick used sparingly: `#8A2D2A`
- Rounded cards, 22-28px radius in mockup language.
- Signature: flat vector dossier/envelope layers, file tabs, seal band doubling as state timeline.
- Typography: Chinese CJK sans for UI, restrained serif for brand/seal labels, mono-like small date/code labels.
