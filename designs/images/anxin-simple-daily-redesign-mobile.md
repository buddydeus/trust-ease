## Layout

Single mobile screen preview, 390 x 844. Show only the daily first-entry declaration status page. The screen should feel almost quiet enough to be used every day: top identity row, one status chip, title, one explanatory sentence, one status strip, two actions, and one small boundary note.

## Modules

- Identity row: `安心` on the left, `今日未申报` status chip on the right.
- Main message: `今天先确认一次`.
- Boundary copy: `只记录你的今日状态，不会触发任何执行。`
- Status strip: `上次申报 昨天 21:08` and `本次状态 等待确认`.
- Primary CTA: `我今天平安`.
- Secondary action: `先看预案`.
- Footer note: `可随时暂停或修改托付内容`.

## Visual Details

Use background `#F6FAF8`, a white content surface, soft panel `#EAF4F1`, primary `#0A6B63`, confirm `#2F8A67`, text `#173B37`, muted `#667B76`, border `#D8E7E2`. Keep the page simple: no bottom navigation, no chart, no multi-card dashboard, no image illustration.
