## 当前事实分层

- 当前实现：单 Expo Router 移动端 App 原型，聚焦单机 MVP、本地数据闭环、
  三语文案、真实截图 QA 和受控皮肤运行时。
- 目标产品：`安心` 是面向高风险事件预案的授权编排、触发判断与执行路由
  平台。
- 目标设计方向：以 `预案` 为主心智，逐步从当前页面结构演进到
  `首页 / 预案 / 执行 / 我的`。
